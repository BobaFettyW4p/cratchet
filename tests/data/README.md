# Test data

| File | What it is |
|---|---|
| `coinbase_sample.jsonl` | Frames from the 2026-11-19 01:53Z ws-feed capture (`scripts/capture_coinbase.py`): the first 1,500 lines, with the three `snapshot` frames removed (they are ~1 MB each) and only every 20th `l2update` kept. 604 ticker, 60 heartbeat, 41 l2update and 1 subscriptions frame. |
| `coinbase_sample.ticks.jsonl` | One line per ticker frame above: the JSON that LedgerFlux's `transform_coinbase_ticker()` and `Tick.model_dump_json()` produce, with `ts_ingest` set to 0. Generated by `scripts/make_golden_ticks.py` against LedgerFlux `004a8c7` (the transform is unchanged on `fix-normalizer-loop`). |

`tests/replay_test.cpp` replays the first file and compares every tick with the second.
Regenerate the golden file whenever LedgerFlux's `Tick` model or ticker transform changes.
